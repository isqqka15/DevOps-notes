**git merge (слияние)** - процесс слияния изменений из одной ветки в данную, с созданием нового коммита, либо использованием [[Коммит (commit)|коммита]] другой ветки
# Визуализация функции merge
```
main:     A──B──C─────F   ← слияние
                 \   /
feature-login:    D──E

```

Как мы видим коммит 'E' слился с веткой main, притом создав коммит 'F'
**git rebase (переснять)** - процесс переноса комитов другой ветки в даную. В отличие от **git merge**, **git rebase** делает перенос всей ветки как будто другая ветка шла сразу после последнего комита данной ветки.
# Визуализация функции rebase
```
A──B──C (main)
    \
     D──E (feature)

A──B──C──D'──E' (feature)
```

Как можно видеть все коммиты из ветки feature: ('D', 'E') были полность перенесены поверх коммита 'C'.
