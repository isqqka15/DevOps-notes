**git branch -f (ИМЯ ВЕТКИ) HEAD~(ЧИСЛО)** - работает таким образом что ветки (ЧИСЛО) коммитов назад (последний коммит включительна) будут висеть в воздухе, и через время будут удалены.
```
# До git branch -f main HEAD~2
A - B - C - D - E
# После git branch -f main HEAD~2
A - B - C -x- D - E # Коммиты D, E стали сиротами
```
