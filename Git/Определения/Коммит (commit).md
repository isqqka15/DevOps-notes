**commit** - снимок текущего состояния проекта 
Коммит внутри себя соддержит:
- Какие файлы были изменены
- Кем и когда
- Сообщение к комиту (комментарий)
- Уникальный идентификатор
### Визуализация коммитов
```css
[Инициализация Git]
        ↓
[Коммит #1] — "Добавлен файл index.html"
        ↓
[Коммит #2] — "Создан стиль для заголовков"
        ↓
[Коммит #3] — "Добавлен JavaScript"
```
