**Тэг - "чекпоинт проекта".** Тэги не двигаются вместе с веткой, а остаются на конкретном [[Коммит (commit)|коммите]]. Тэги показывают снимок проекта на момент создания тэга.
```
# 1.0, 1.1 являются тегами, и прикреплены к коммиту C и E
        1.0    1.1
A - B - C - D - E 
```

Еще как я заметил невалидным именем для тега будет тег содержащий точку на конце. К примеру:
```bash
git tag 1.0 # Так можно назвать тег.

git tag 1.0. # Выдаст ошибку о невалидном имени тега
```

Также при переходе к старому тэгу, мы находимся в состоянии [[HEAD|DETACHED HEAD]]. Дабы выйти из него мы используем:
```bash
git checkout main # То есть просто переходим к нашей ветке.
```

И мы оказываемся на [[Ветка(branch)|ветке]] main, т.е. на последнем коммите.
