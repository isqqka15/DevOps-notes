**HEAD** - указатель на коммит или текущую ветку.
<mark style="background:#ff4d4f">!ВАЖНО: HEAD может использоваться в связке с различными коммандами.</mark>
Detached HEAD - состояние когда HEAD указывает не на ветку, а на какой либо другой коммит.
**git checkout (hash)** - позволяет перейти к определенному коммиту используя [[Хэш (hash)|хеш]] коммита.
> В состояние detached HEAD можно работать, главное затем создать новую ветку дабы не потерять изменения.

Так же, что бы каждый раз не переходить по хэшу коммита можно воспользоваться: **HEAD^**, где кол - во стрелок будет обозначать кол-во шагов назад по коммитам.
**git checkout HEAD^** - переходит на один коммит назад.
```
A──B──C──D (HEAD)
         ↑
     git checkout HEAD^  → попадаешь в C
```

Либо же можно воспользоваться **HEAD~(ЧИСЛО)**, если требуеться откатиться на большое кол-во коммитов назад.
- HEAD~1 = HEAD^
- HEAD~2 = HEAD^^
- И так далее.
