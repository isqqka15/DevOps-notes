**git init** - иницализировать локальный репозиторий в данной 
директории(создает скрытую папку *.git* со всей историей проекта)

**git add (ИМЯ ФАЙЛА)** - добавить файлы в следущий [[Коммит (commit)|коммит]]
```bash
# добавляет в следущий коммит pipiska.py
git add pipiska.py
```

**git status** - показывает текущее состояние репозитория:
- Какие файлы были изменены
- Что добавлено/не добавлено в коммит
```bash
# Показывает какие файлы были изменены, а также что было добавлено/не добавлено
git status
```

**git commit -m (комментарий)** - создает коммит с коментарием
**git branch (ИМЯ ВЕТКИ)** - создает [[Ветка(branch)|ветку]], не переходя в нее
```bash
# создает ветку
git branch feature 

# откатывает ветку на n-ое кол-во коммитов, таким образом что последние коммиты начинают висеть в воздухе.
git branch -f (ИМЯ ВЕТКИ) HEAD~(ЧИСЛО)

```

**git checkout** - переходит по чему либо.
**[[HEAD|git checkout (hash)]]** - переход к коммиту по кэшу.
**[[HEAD| git checkout HEAD^]]** - переход на один коммит назад.
```bash
# Переход к определенному коммиту по хэшу
git checkout <hash> 

# Переходит к ветке
git checkout <имя ветки>

# Переходит к коммиту по хэшу
git checkout <хэш коммита>

# Переход по одному коммиту назад.
git checkout HEAD^
```

**[[git merge & git rebase|git merge]] - обьединение изменений из одной ветки в другую
```bash
# Обьединяет послений коммит из feature, в ветку main
git merge feature
```

[[git merge & git rebase|git rebase]]** - перенос коммитов с другой ветки на данную.
```bash
# Переносит все коммиты из ветки feature поверх последнего коммита ветки main
git rebase feeature
```

**git remote add origin (URL)** - связать локальный репозиторий с GitHub
```bash
# Связывает локальный репозиторий с GitHub
git remote add origin <URL> # origin становится <URL>
```

**git push -u origin main** - пуш проекта на гитхаб (в первый раз)
```bash
# Пушит данную ветку в origin, т.е. main
git push -u origin main
```
**git push** - пуш проекта на гитхаб
```bash
git push
```

**git log --oneline** - показывает всю историю коммитов, в одну строку.
```bash
# git log выводит все в таблицу или типа того, а --oneline в одну строку
git log --oneline
```

**git show HEAD^** - показывает что было один комит назад.
```bash
git show HEAD^
```

**git reset** - откатывает комиты назад(может удалить их). **--soft**: удаляет код, но сохраняет его в файлах проекта, **--hard**: <mark style="background:#ff4d4f">полностью удаляет код</mark>.
```bash
# По умолчанию используется используется флаг --soft
git reset HEAD~(ЧИСЛО)
# При использовании флага --hard, удаляется всякое присутствие кода
git reset --hard HEAD~(ЧИСЛО)
```

**git revert** - создает отменяющий коммит, который удаляет изменения и в тоже время показывает, что здесь что то было удалено.
```bash
# Показывает явно что здесь было что то удалено
git revert <hash>
# Или же 
git revert HEAD~<num>
# Затем открывается редактор кода и там прописываем коммит

# Либо же можно не открывая редактор, прописать коммит
git revert --no-edit e5f6g7h
```
**git restore** - отменяет изменения если не было прописано **git add** или **git commit**
```bash
# Для отмены одного файла 
git restore pipiska.py

# Для отмены всех файлов 
git restore .
```
