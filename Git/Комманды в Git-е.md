**git init** - иницализировать локальный репозиторий в данной директории(создает скрытую папку *.git* со всей историей проекта)
**git add <ИМЯ ФАЙЛА>** - добавить файлы в следущий [[Коммит (commit)|коммит]]
**git status** - показывает текущее состояние репозитория:
- Какие файлы были изменены
- Что добавлено/не добавлено в коммит
**git commit -m (комментарий)** - создает коммит с коментарием
**git branch <ИМЯ ВЕТКИ>** - создает [[Ветка(branch)|ветку]], не переходя в нее
**git checkout <ИМЯ ВЕТКИ>** - переходит в ветку.
**[[git merge & git rebase|git merge]] <ИМЯ ВВЕТКИ>** - обьединение изменений из одной ветки в другую
**[[git merge & git rebase|git rebase]]** - перенос коммитов с другой ветки на данную.
**git remote add origin <URL>** - связать локальный проект с GitHub
**git push -u origin main** - пуш проекта на гитхаб (в первый раз)
**git push** - пуш проекта на гитхаб
