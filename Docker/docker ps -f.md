Используя [[Комманды Docker|docker ps -f]]  можно находить контейнеры по определенным критериям:

Критерий exited позволяет найти контейнеры по [[Коды в Docker|коду завершения]]:
```bash
exited = <код>

# Примеры кодов
exited = 0 # контейнер завершился нормально
```

Критерий status позволяет найти контейнеры по их статусу выполнения:
```bash
status = <тип статуса>

# Примеры  статусов
status = running # контейнер до сих пор работает 
status = created
status = paused
status = exited
status = restarting

```
