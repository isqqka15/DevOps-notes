**FROM** - взять образ и строится поверх него. 
```bash
FROM <имя образа с докерхаб или другого репозитория>
```

**RUN**  - запустить команду в процессе сборки, причем каждая новый **RUN** плодит новые слои, поэтому желательно обьединять команды.
```bash
RUN sudo apt install \
	fastfetch \
	...
```

**COPY** - перенос файлов с хоста в контейнер
```bash
COPY <локальный путь> <путь в контейнере>
```

**ADD** -  как **COPY**  но продвинутей (позволяет распаковывать [[В чем разница между tar, bzip2, gzip|tar архивы]] или же скачивать и добавлять файлы через URL)
```bash
ADD <локальный путь или URL> <путь в контейнере>
```

**CMD** - запускает комманды, а если при запуске контейнера передались другие комманды "**[[Bash синтаксис|bash]]**" и т.д. 
```bash
CMD ["python", "main.py"]
```

**ENTRYPOINT** - запускает комманды, но если при запуске контейнера передались другие комманды, то они просто добавятся к **ENTRYPOINT**.
```bash
ENTRYPOINT ["python", "main.py"]
```
