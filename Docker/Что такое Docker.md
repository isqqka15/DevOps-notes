Docker - это утилита позволяющая создавать на основе образов, контейнеры содержащие внутри себя все нужное для запуска приложения

Что такое **образ (image)?** - это файл где собрана вся информация для создания контейнеров. Он содержит
-  Нужные настройки проекта
-  Нужные комманды запуска
- Облегченный образ ос без ядра
-  Нужные библиотеки
-  Файлы проекта
-  Нужные программы

Что **контейнер** содержит внутри себя:
-  Облегченный образ ос без ядра
-  Нужные библиотеки
-  Файлы проекта
-  Нужные программы
