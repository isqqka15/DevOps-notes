Итак допустим мы хотим остановить все контейнеры. Для этого мы используем комманды **[[Комманды Docker|docker stop]]** и **[[Комманды Docker|docker ps -q]]**.  Дабы в **docker stop** подставить id контейнеров мы используем **[[Bash синтаксис|$()]]** т.е подстановку вывода комманду. Выглядит это примерно так:
```bash
docker stop $(docker ps -q)
```
