**Ссылки** - это переход к директории или к файлу.
#### Различия между мягкой и твердой ссылкой:

| Тип ссылки               | Мягкая                         | Твердая                                                                    |
| ------------------------ | ------------------------------ | -------------------------------------------------------------------------- |
| На что указывает         | На путь к директории или файлу | На индекс(хз что это)                                                      |
| Если удалить файл        | Будет показывать в никуда      | Все равно будет показывать содержимое файла, пока есть одна твердая ссылка |
| Для кого можно создавать | Для всех                       | Только для файлов                                                          |
