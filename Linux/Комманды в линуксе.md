**cd (change directory)**  - переход по директории в линукс
```bash
# Можно перейти без полного пути, но для этого надо находится в директории в которой распологается эта директория :
cd Документы
cd Загрузки
cd ...

# Или же используя полный путь :
cd Документы/папка1/папка2/...

# Так же можно переходить используя точки, где .. обозначает директорию выше :
cd ../..

# Дабы сразу вернуться в домащнюю директорию можно воспользоваться этими коммандами :
cd 
cd /home/<имя пользователя>
cd ~
```

**pwd (print working directory)** -  показывает полный путь до директории в которой мы находимся.
```bash
pwd

# К примеру pwd может вывести такое
/home/isqqka
```

**ls (list)**  -  показывает содержимое директории 
```bash
# Просто покажет содержимое
ls 

# Показывает все файлы
ls -a # флаг -a расшифровывается как 'all'

# Показывает дополнительную информацию о содержимом
ls -l

# Флаги можно комбинировать: к примеру -la выведет все скрытые файлы и покажет о всех файлах инфу. Порядок флагов не важен

ls -la

# Можно также просмотреть директорию в которой ты не находишься
ls <путь до директории>

# C помощью флага -R можно посмотреть углубленный вывод т.е. показать файлы и директории внутри директории
ls -R
```

**cat** - показывает содержимое файла сразу (<mark style="background:#ff4d4f">ТОЛЬКО ТЕКСТОВЫЙ ФОРМАТ!</mark>)
```bash
cat <название файла>
```

**more** - показывает содержимое файла, в просматривальщике файлов (<mark style="background:#ff4d4f">ТОЛЬКО ТЕКСТОВЫЙ ФОРМАТ!</mark>)
```bash
more <название файла>
```

**less** - показывает содержимое файла, но в другом просматривальщике файлов (<mark style="background:#ff4d4f">ТОЛЬКО ТЕКСТОВЫЙ ФОРМАТ!</mark>)
```bash
less <название файла>
```

**touch**  -  создает пустой файл
```bash
# Создает один файл за раз
touch <название файла>

#Создает несколько файлов за раз
touch <название файла> <название файла> <название файла> <название файла>
```

**cp** - копировать файл
```bash
# Можно указать полный путь копирования файла
cp <имя файла> <полный путь>

# Или же если директория куда копировать файл находится в одной директории с файлом пишется так :
cp <имя файла> <имя директории>

# Можно также просмотреть кто куда и что скопировалось используя флаг -v
cp -v <имя файла> <путь>

# Что бы скопировать директорию в директорию используем флаг -R
cp -R <директория> <другая директория>
```

**mv** - копировать или же переимновать файл/директорию
```bash
# Что бы переместить файл
mv <имя файла> <путь>

# Что бы переимновать файл
mv <имя файла> <новое имя файла>

# Что бы переименовать директорию
mv <имя директории> <новое имя директории>
```

**rm**  - удалить файл/ директории
```bash
# Удалит файл
rm <имя файла>

#Удалит директорию и все содержимое в ней
rm -R <имя директории>
```

**mkdir** - создать директорию
```bash
# Создать директорию
mkdir <имя директории>

# Если мы хотим создать цепочку директорий то пишем так, но для этого надо что бы первая директория существовала.
mkdir <имя директории>/<имя директории>/...

# Если же мы хотим что бы сразу создалась директория то пишем с флагом -p
mkdir -p <имя директории>/<имя директории>/...
```

**rmdir** - стирает директорию, только если она пустая.
```bash
rmdir <имя директории>
```

**ln - создание [[Ссылки (link)|ссылки]]
```bash
# Создание ссылки на директорию
ln -s <полный путь до директории> <имя ссылки>

# Создание ссылки на файл
ln -s <полный путь до файла> <имя ссылки>

# Создание жесткой ссылку ТОЛЬКО НА ФАЙЛ
ln <полный путь до файла> <имя ссылки>
```

**find** - ищет файлы
```bash
# Ищет файлы по флагам
find <путь> -<flag> "паттерн"
find /home -name "*.txt"
find / -name "readme.txt"
```

**wc** - выводит кол-во строк, слов и байт в файле
```bash
# Выводит все аттрибуты
wc <имя файла>

# Выводит только кол-во строк
wc -l <имя файла>

# Выводит только кол-во слов
wc -l <имя файла>
```

**sort** -  Выводит сортированный файл, <mark style="background:#ff4d4f">ПРИ ЭТОМ НЕ ИЗМЕНЯЯ ФАЙЛ</mark> .
```bash
# Сортирует по буквам
sort <имя файла>

# Сортирует по номерам
sort -n <имя файла>
```

**cut** - выводит определнное поле из текста
```bash
# Разделяет файл используя флаг -d для разделителя, -f для числа поля идущего по счету, и имя файла
cut -d "разделитель" -f <число по счету поля> <имя файла>
```

**grep** - поиск определенного слова в файле. Можно использовать [[Регулярные Выражения|регулярные выражения]].
```bash
# Поиск слова в файле
grep <слово которое надо найти> <в какой директории ищем>/<в каких файлах>

# Ищем в текущей директории (.), во всех файлах (*) содержащие слово linux
grep linux ./*

# Что бы отменить чувствительность к регистру используем флаг -i
grep -i linux ./*

# Также дабы упростить работу можно использовать регуляерные выражения. Что бы их использовать используется флаг -E и звездочку. К примеру если надо найти email
grep -E "[A-Za-z\.]*@[A-Za-z]*.gov" <имя файла>
```

**tar** - обьединяет все файлы в один файл, но [[В чем разница между tar, bzip2, gzip|не умеет их компресировать]] (ну почти)
```bash
# Паттерн комманды
tar <флаги> <название будущего архива> <файлы которые туда попадут>

# Создание файла mytar.tar где будет Folder1. флаг c - create, f - file
tar cf mytar.tar Folder1

# Распаковка файла
tar xf mytar.tar

# А если нам надо глянуть что у нас внутри архива используем флаг t - test
tar tf mytar.tar

# А если надо сразу и обьеденить и зазипить то
tar czf mytar.tar Folder1

# А если надо распаковать
tar cjf 
```

**gzip, bzip, xz** - компресируют файлы в формат gz и bz2 соответсвенно, но [[В чем разница между tar, bzip2, gzip|не умеют обьединять файлы]]
```bash
# Что бы закомпресировать отедльный файл или .tar
gzip, bzip2, xz <имя тара>
# Что бы раскомпресировать отдельный файл или .tar
gunzip, bunzip2, unxz <имя тара>
```

**zip** -  ну это для виндузятников
```bash
# Для архивирования
zip -r <имя архива> <имя папки которую мы запаковывакем>

# Для разархивирования
unzip <имя архива>
```

**ps** - показывает запущенные процессы
```bash
# Показывает процессы привязанные к терминалу данного пользователя
ps

# Показывает явные процессы другого пользователя
ps -u <имя пользователя>

# Показывает твои процессы не привязанные к терминалу
ps x 

# Ищет конкретный процесс по имени
ps -C [имя процесса]

# Показывает расширенную информацию, понятную для человека
ps -f

# Показывает процессы привязанные к терминалу всех юзеров
ps -a

# Показывает всех юзеров, в удобном формате, и добавляет процессы не привязанные к терминалу
ps aux

# Для отсеивания не нужного используем
ps aux | grep <название>
```
