Вывод из одной комманды можно передавать в другую комманду. Но в отличии от [[Комбинирование комманд|комбинирования комманд]] их вывод можно будет куда то сохранить. К примеру:
```bash
# Перенаправляем вывод отсортированных имен из names.txt в names_sorted.txt
sort names.txt > names_sorted.txt

# Если мы хотим добавить туда и числа надо добавить, то дабы не перезаписать файл пишем >>
sort numbers.txt >> names_sorted.txt
```

Так же при выводе есть два потока (условно) хорошие (выполненые комманды) и плохие (невыполненные комманды). Если например мы не хотим видеть ошибки мы можем их перенаправить в никуда.
```bash
# Второй поток уйдет в никуда
grep linux /etc/* 2> 

# Или же можем перевести в /dev/null
grep linux /etc/* 2>

# А если мы хотим один поток в одно место вывести, а второй в другое место то пишем вот так
grep linux /etc/* > good.txt 2> ungood.txt # то есть первый вывод идет в good.txt, а 2 вывод в ungood.txt

# А если хотим перевести все потоки то используем &
grep linux /etc/* & > kudato.txt

```
