В линуксе можно комбинировать комманды, и допустим вывод из одной сразу отдать другой. К примеру возьмем комманду [[Комманды в линуксе|cut]] и [[Комманды в линуксе|sort]]
```bash
# По умолчанию cut только выводит определенное поле из текста
cut -d "разделитель" -f <число по счету поля> <имя файла>

# НО добавив через разделитель | в конце комманды cut, можно сразу передать cut в комманду sort тем самым отсортировав вывод
cut -d "разделитель" -f <число по счету поля> <имя файла> | sort

```

И так можно бесконечно комбинировать комманды.
