Ну кароче bash это скриптовый язык програмированния поэтому он юзает [[Комманды в линуксе|комманды линукса]].


**$0** - имя скрипта, это зарезервированное значение.
$<число> - это как бы input. Т.е. в программу поступят такие и такие значения

**Переменные**:
- Переменные бывают двух типов
1. Можно просто дать им через ' ' число или текст
2. Или через \` \` выдать им значение какой то программы
```bash
num=1
out=`ls -a`
```

Дабы юзать переменные нужно их указать через $
```bash
message='Hello World!'
echo '$message'
```

Если же нужно использовать сумму то юзаем **(())**:
```bash
num1=50
num2=30
summa=$((num1+num2))
```

Условия пишутся так
```bash
# В данном примере используется if. десь мы смотрим является ли первый ввод "Vasya", если не вася а трамп, и даже если не трамп то
if ["$1" == "Vasya"]; then
	echo "Privet $1"
elif ["$1" == "Trump"]; then
	echo "Hello $1"
else echo "Zdarova $1"
fi # fi обозначает конец if

# В этом случае мы используем case
x = $2 # первый параметр игнорится
case $x in # то есть для второго инпута, перебираются варианты
	1) echo "This is one";;
	[2-9]) echo "Two nine";;
	"Petya") echo "Privet $x";;
	*) echo "Unknown"
esac
	
```

**read** - позволяет сделать как бы как input в питоне
```bash
# Флаг -p показывает текст перед вводом
read -p "Write smth" x

# Флаг -s не показывает кол-во символов
read -sp "Write your password" x

# Флаг -t ограничивает время ожидания. Тут к примеру 5 сек
read -t 5 -p "Введите ответ или подождите" x

# Ограничивает кол-во символов вводимых  
read -n 1 -p "Введите y/n что бы продолжить" x 
```

Как делать цикл **for** 
```bash
# Здесь мы читаем текст с каждого файла который .txt
for myfile in *.txt; do  
       cat "$myfile"  
done

# Либо же если мы хотим сделать что то несколько раз то нам надо писать вот так
for x in {1..10}; do
		echo "X = $x"
done

for (( i=1; i<=10; i++ )); do
		echo "Nomer I = $i"
```

Как писать **функции** и вызвать их
```bash
# Здесь функция без return
myFunction()
{
	echo "ХУЙ"
}
myFunction 

# Что бы включить return надо какой то глобальной переменной присвоить значение из функции
summa = 0
myFunction()
{
summa=$(($1+$2))
}
myFunction 50 10
echo "$myFunction"

```
